PDF AI 문제 자동 생성기 V2
==============================

[설치]
1. Python이 설치되어 있어야 합니다.
2. install.bat을 한 번 실행합니다.
3. 설치가 끝나면 run.bat을 실행합니다.

[사용]
1. 브라우저가 열리면 PDF를 업로드합니다.
2. 왼쪽에서 문제 수/난이도/문제 유형을 선택합니다.
3. OpenAI API Key를 입력합니다.
4. 'AI 문제 생성하기'를 누릅니다.

[중요]
- AI 문제 생성을 위해 OpenAI API Key가 필요합니다.
- ChatGPT Plus/Free 구독과 OpenAI API 사용료는 별개입니다.
- API Key는 프로그램에 저장하지 않으며 화면 입력값으로만 사용합니다.
- API 사용 시 선택한 모델의 API 요금이 발생할 수 있습니다.
- 현재 버전은 텍스트 기반 PDF를 대상으로 합니다. 스캔 이미지 PDF는 OCR 기능이 필요합니다.

[업그레이드 내용]
- 단순 빈칸 문제 방식 제거
- 4지선다 문제 생성
- 개념/임상/사례/옳고그름 유형
- 난이도 설정
- 정답 및 해설
- 시험지/정답해설 파일 분리
